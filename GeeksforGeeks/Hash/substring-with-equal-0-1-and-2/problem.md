# GFG. Substring with Equal 0, 1 and 2
**Platform:** GeeksforGeeks
**Difficulty:** N/A
**Topic:** Hash

## Problem Statement
Given a string s which consists of only 0, 1 or 2s, count the number of substring which have equal number of 0s, 1s and 2s.

 Examples:

Input: s = “0102010”
Output: 2
Explanation: Substring s[2, 4] = “102” and substring str[4, 6] = “201” have equal number of 0, 1 and 2 

Input: s = “11100022”
Output: 0
Explanation: There is no substring with equal number of 0, 1 and 2.

Constraints:
1 ≤ |s| ≤ 105
